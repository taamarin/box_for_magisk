## ВНИМАНИЕ
Этот проект не несет ответственности за: поврежденные устройства, испорченные SD-карты или сгоревшие процессоры (SoC).

**Пожалуйста, убедитесь, что ваши конфигурационные файлы не создают петли трафика, так как это может привести к бесконечной перезагрузке вашего телефона.**

Если вы понятия не имеете, как настроить этот модуль, вам могут понадобиться такие приложения, как **ClashForAndroid, ClashMetaForAndroid, v2rayNG, Surfboard, SagerNet, AnXray, NekoBox** и т.д.

## Установка
- Скачайте zip-архив модуля из раздела [RELEASE](https://github.com/taamarin/box_for_magisk/releases) и установите его через `Magisk/KernelSU`. Во время установки вас спросят, нужно ли скачивать полный пакет. Вы можете выбрать либо **полную загрузку (complete download)**, либо **отдельную загрузку (separate download)** позже, затем перезагрузите устройство.
- Этот мод поддерживает прямые обновления в `Magisk/KernelSU Manager` (обновленные моды вступят в силу без перезагрузки устройства).

### Обновление ядер
Этот модуль включает в себя следующие ядра:
- [clash](https://github.com/Dreamacro/clash) (ветка master удалена)
- [clash.meta](https://github.com/MetaCubeX/Clash.Meta) (архивировано, ветки изменены, контент на месте)
- [sing-box](https://github.com/SagerNet/sing-box)
- [v2ray-core](https://github.com/v2fly/v2ray-core)
- [Xray-core](https://github.com/XTLS/Xray-core)

Соответствующая конфигурация для ядра — `${bin_name}`, для которой можно установить значения (`clash` | `xray` | `v2ray` | `sing-box`).

Каждое ядро работает в директории `/data/adb/box/bin/${bin_name}`, а имя ядра определяется параметром `bin_name` в файле `/data/adb/box/settings.ini`.

Убедитесь, что вы подключены к интернету, и выполните следующую команду для обновления файла ядра:

```shell
# Обновить выбранное ядро на основе `${bin_name}`.
su -c /data/adb/box/scripts/box.tool upkernel
```

Если вы используете `clash/sing-box` в качестве выбранного ядра, вам также может потребоваться выполнить следующую команду для открытия панели управления:

```shell
# Обновить панель управления для `clash/sing-box`.
su -c /data/adb/box/scripts/box.tool upyacd

Кроме того, вы можете обновить всё сразу (это может занять лишнее место в памяти):

```shell
# Обновить все файлы, включая различные типы ядер.
su -c /data/adb/box/scripts/box.tool all
```

## Конфигурация
**Следующие основные сервисы далее именуются BFM:**
- Основные сервисы в совокупности называются BFM.
- Вы можете включать или отключать модуль для запуска или остановки сервисов BFM в режиме реального времени через приложение Magisk/KernelSU Manager без необходимости перезагрузки устройства. Запуск сервиса может занять несколько секунд, а остановка вступит в силу немедленно.
### Конфигурация ядра
- Для настройки основного ядра (`bin_name`), пожалуйста, обратитесь к разделу **Обновление ядер**.
- Каждый файл конфигурации ядра должен быть настроен пользователем индивидуально; скрипт автоматически проверит валидность внесенных настроек. Результаты этой проверки будут сохранены в файле `/data/adb/box/run/runs.log`.
- Совет: И `clash`, и `sing-box` поставляются с предустановленными скриптами для реализации прозрачного прокси. Для более детальной настройки, пожалуйста, обратитесь к официальной документации. Ссылки на документацию: [Официальная документация Clash](https://github.com/Dreamacro/clash/wiki/configuration) (ветка master удалена), [Официальная документация sing-box](https://sing-box.sagernet.org/configuration/outbound).

### Чтобы применить фильтрацию с использованием черного или белого списков, выполните следующие шаги:
- По умолчанию BFM предоставляет прокси для всех приложений (APP) всех пользователей Android.
- Если вы хотите, чтобы BFM проксировал все приложения, за исключением некоторых, откройте файл `/data/adb/box/settings.ini`, измените значение `proxy_mode` на `blacklist` (по умолчанию) и добавьте приложения, которые нужно исключить, в `packages_list`. Например: **packages_list=("com.termux" "org.telegram.messenger")**.
- Если вы хотите проксировать только определенные приложения, используйте режим `whitelist`.
- Когда значение `proxy_mode` установлено на `TUN`, прозрачный прокси не будет функционировать, и только соответствующее ядро начнет поддерживать режим **TUN**. На данный момент это доступно **только для ядер clash и sing-box**.
> **Примечание: При использовании Clash черный и белый списки не работают в режиме fake-ip.**

### Прозрачное проксирование для конкретных процессов
- По умолчанию BFM выполняет прозрачное проксирование для всех процессов.
- Если вы хотите, чтобы BFM проксировал все процессы, за исключением определенных, откройте файл `/data/adb/box/settings.ini`, измените значение `proxy_mode` на `blacklist` (значение по умолчанию), затем добавьте GID (ID групп) в массив `gid_list`, разделяя их пробелами. В результате процессы с соответствующими GID **не будут проксироваться**.
- Если вы хотите выполнять прозрачное проксирование только для определенных процессов, установите значение `proxy_mode` на `whitelist` и добавьте GID в массив `gid_list` через пробел. В этом случае **будут проксироваться** только процессы с соответствующими GID.
> **Совет:** Поскольку iptables в Android не поддерживает сопоставление по PID (ID процесса) напрямую, сопоставление процессов в Box выполняется косвенно через GID. В Android вы можете использовать команду `busybox setuidgid`, чтобы запустить конкретный процесс с определенным UID и любым GID.

### Чтобы изменить режим прокси в BFM, выполните следующие шаги:
- BFM использует TPROXY для прозрачного проксирования TCP+UDP трафика (по умолчанию). Если будет обнаружено, что устройство не поддерживает TPROXY, откройте файл **/data/adb/box/settings.ini** и измените значение на `network_mode="redirect"`, что задействует только TCP-проксирование.
- Откройте файл `/data/adb/box/settings.ini` и установите значение `network_mode` на **redirect, tproxy или mixed**.
- **redirect**: использование режима redirect для проксирования TCP.
- **tproxy**: использование режима tproxy для проксирования TCP + UDP.
- **mixed**: использование режима redirect для TCP и режима TUN для UDP трафика.
- Обязательно сохраните изменения в файле конфигурации и перезапустите службу BFM или устройство, чтобы изменения вступили в силу.

### Обход прозрачного прокси при подключении к Wi-Fi или точке доступа в BFM
- По умолчанию BFM прозрачно проксирует трафик локального хоста (localhost) и точки доступа (включая USB-модем).
- Откройте файл **/data/adb/box/settings.ini** с помощью текстового редактора. Найдите параметр `ignore_out_list` и добавьте к нему значение `wlan+`. Это позволит обходить прозрачный прокси при использовании Wi-Fi соединений.
- Если вы хотите включить проксирование для точек доступа (hotspot), выполните следующие дополнительные шаги:
  - Найдите параметр `ap_list` в файле `settings.ini`.
  - Добавьте к значению `ap_list` строку `wlan+`. Это активирует проксирование для раздаваемых точек доступа.
- Для устройств на базе **Mediatek** может потребоваться указать **ap+ / wlan+**.
- Если вы не уверены в названии интерфейса точки доступа (AP), вы можете воспользоваться командой **ifconfig** в терминале, чтобы определить его имя.

### Включение заданий Cron для автоматического обновления баз Geo и подписок по расписанию
- Откройте файл **/data/adb/box/settings.ini** с помощью текстового редактора.
- Найдите в файле параметр `run_crontab`.
- Измените значение `run_crontab` на `true`.
- Настройте параметр `interval_update` в соответствии с желаемым расписанием. Значение по умолчанию — **@daily**, что означает обновление один раз в день. Вы можете установить свой интервал, используя синтаксис cron.
- Сохраните изменения в файле конфигурации.
- Чтобы запустить задание Cron и инициировать обновления, выполните следующие действия:

```shell
  # выполнить команду
  su -c /data/adb/box/scripts/box.service cron
```

- Эта команда запустит задание Cron и инициирует обновление баз Geo и подписок согласно настроенному расписанию.
- Убедитесь, что у вас есть необходимые права для выполнения команды. После включения Cron Job и выполнения команды обновления будут происходить автоматически в соответствии с указанным графиком.

## Запуск и остановка
### Ручной режим (manual mode)
- Если вы хотите полностью контролировать BFM, выполняя команды вручную, вы можете создать файл с именем **/data/adb/box/manual**. В этом случае служба BFM не будет запускаться автоматически при включении устройства, и вы не сможете управлять запуском или остановкой службы через приложение Magisk/KernelSU Manager.
- Создавая файл **/data/adb/box/manual**, вы берете на себя ручное управление BFM и можете выполнять команды по мере необходимости для управления его работой. Пожалуйста, обратите внимание, что изменение системных файлов требует соответствующих разрешений, и любые ручные изменения следует вносить с осторожностью.

### Запуск и остановка службы управления
- Скрипт службы BFM находится по пути `/data/adb/box/scripts/box.service`

```shell
# Старт BFM
  su -c /data/adb/box/scripts/box.service start &&  su -c /data/adb/box/scripts/box.iptables enable

# Стоп BFM
  su -c /data/adb/box/scripts/box.iptables disable && su -c /data/adb/box/scripts/box.service stop
```

- When executing these commands, the Terminal will print logs simultaneously and output them to the log file.

- При выполнении этих команд терминал будет одновременно выводить логи на экран и записывать их в лог-файл.

## Подписки и обновление баз данных Geo
Чтобы обновить подписку и базу данных Geo одновременно, вы можете использовать следующую команду:

```shell
  # Эта команда обновит и подписку, и базу данных Geo в одно время.
  su -c /data/adb/box/scripts/box.tool geosub
```

Кроме того, если вы предпочитаете обновлять их по отдельности, вы можете использовать следующие команды:

### Обновление подписки:

```shell
  # Эта команда обновит данные подписки.
  su -c /data/adb/box/scripts/box.tool subs
```

Выполняя эти команды, вы сможете обновлять подписки и базы данных Geo по мере необходимости.

### Обновление базы данных Geo:

```shell
  # Эта команда обновит базу данных Geo.
  su -c /data/adb/box/scripts/box.tool geox
```

## Дополнительные инструкции:
- При изменении любых конфигурационных файлов ядра убедитесь, что настройки, связанные с **tproxy**, соответствуют определениям в файле **/data/adb/box/settings.ini**.
- Если ваше устройство имеет публичный IP-адрес, вы можете добавить этот IP-адрес во внутреннюю сеть в файле **/data/adb/box/scripts/box.iptables**, чтобы предотвратить появление петлевого трафика (loopback traffic).
- Логи службы BFM можно найти в директории **/data/adb/box/run**.
- Обратите внимание, что редактирование этих файлов требует соответствующих прав доступа. Пожалуйста, внимательно следуйте инструкциям и проверяйте корректность любых изменений, внесенных в конфигурационные файлы.

You can run the following command to get other related operating instructions:

Вы можете запустить следующие команды, чтобы получить другие инструкции по эксплуатации:

```shell
  su -c /data/adb/box/scripts/box.tool
  # использование: {check|bond0|bond1|memcg|cpuset|blkio|geosub|geox|subs|upkernel|upyacd|upyq|upcurl|port|reload|all}
  su -c /data/adb/box/scripts/box.service
  # использование: $0 {start|stop|restart|status|cron|kcron}
  su -c /data/adb/box/scripts/box.iptables
  # использование: $0 {enable|disable|renew}
```

## Удаление
- Удаление этого модуля через Magisk/KernelSU Manager приведет к удалению файла **/data/adb/service.d/box_service.sh** и директории данных BFM **/data/adb/box**.
- Удалите директорию данных BFM, выполнив следующую команду:

```shell
  # Эта команда удалит директорию данных BFM, расположенную в /data/adb/box.
  su -c rm -rf /data/adb/box
  su -c rm -rf /data/adb/service.d/box_service.sh
  su -c rm -rf /data/adb/modules/box_for_root
```
