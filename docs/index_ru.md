## ВНИМАНИЕ
Проект не несет ответственности за повреждение устройств, SD-карт или SoC.

**Убедитесь, что файлы конфигурации не создают циклы трафика: это может привести к постоянной перезагрузке телефона.**

Если вы понятия не имеете, как настроить этот модуль, вам могут понадобиться такие приложения, как **ClashForAndroid, ClashMetaForAndroid, v2rayNG, Surfboard, SagerNet, AnXray, NekoBox** и т.д.

## Установка
- Скачайте ZIP-архив модуля со страницы [Releases](https://github.com/taamarin/box_for_magisk/releases) и установите его через `Magisk/KernelSU`. Во время установки появится запрос на загрузку полного пакета. Вы можете скачать все файлы сразу или загрузить их по отдельности позже. После установки перезагрузите устройство.
- Модуль можно обновлять непосредственно через `Magisk/KernelSU Manager`; обновления вступают в силу без перезагрузки устройства.

### Обновление ядер
Этот модуль включает в себя следующие ядра:
- [clash](https://github.com/Dreamacro/clash) (ветка master удалена)
- [clash.meta](https://github.com/MetaCubeX/Clash.Meta) (архивировано, ветки изменены, контент на месте)
- [sing-box](https://github.com/SagerNet/sing-box)
- [v2ray-core](https://github.com/v2fly/v2ray-core)
- [Xray-core](https://github.com/XTLS/Xray-core)

Имя используемого ядра задается параметром `${bin_name}`. Допустимые значения: `clash`, `xray`, `v2ray` и `sing-box`.

Каждое ядро запускается из каталога `/data/adb/box/bin/${bin_name}`. Имя ядра задается параметром `bin_name` в файле `/data/adb/box/settings.ini`.

Убедитесь, что вы подключены к интернету, и выполните следующую команду для обновления файла ядра:

```shell
# Обновить выбранное ядро на основе `${bin_name}`.
su -c /data/adb/box/scripts/box.tool upkernel
```

Если вы выбрали `clash` или `sing-box`, для установки панели управления также может потребоваться выполнить следующую команду:

```shell
# Обновить панель управления для `clash/sing-box`.
su -c /data/adb/box/scripts/box.tool upyacd

Кроме того, можно обновить все файлы сразу, хотя это может занять больше места, чем необходимо:
```

```shell
# Обновить все файлы, включая ядра разных типов.
su -c /data/adb/box/scripts/box.tool all
```

## Конфигурация
**Основные сервисы модуля далее именуются BFM.**
- Вы можете запускать и останавливать BFM, включая или отключая модуль в приложении Magisk/KernelSU Manager, без перезагрузки устройства. Запуск сервиса может занять несколько секунд, а остановка вступает в силу немедленно.
### Конфигурация ядра
- О выборе ядра с помощью параметра `bin_name` см. раздел **Обновление ядер**.
- Настройте файл конфигурации каждого ядра. Скрипт проверит корректность настроек и сохранит результаты в `/data/adb/box/run/runs.log`.
- **Совет:** `clash` и `sing-box` включают скрипты для настройки прозрачного прокси. Дополнительные сведения см. в официальной документации: [Clash](https://github.com/Dreamacro/clash/wiki/configuration) (ветка master удалена) и [sing-box](https://sing-box.sagernet.org/configuration/outbound).

### Чтобы применить фильтрацию с использованием черного или белого списков, выполните следующие шаги:
- По умолчанию BFM проксирует трафик всех приложений всех пользователей Android.
- Чтобы проксировать все приложения, кроме выбранных, откройте `/data/adb/box/settings.ini`, установите `proxy_mode` в `blacklist` (значение по умолчанию) и добавьте исключаемые приложения в `packages_list`. Например: **packages_list=("com.termux" "org.telegram.messenger")**.
- Чтобы проксировать только выбранные приложения, используйте режим `whitelist`.
- Если `proxy_mode` установлен в `TUN`, прозрачное проксирование отключается и используется режим TUN выбранного ядра. Сейчас его поддерживают **только clash и sing-box**.
> **Примечание:** При использовании Clash черный и белый списки не действуют в режиме fake-IP.

### Прозрачное проксирование для конкретных процессов
- По умолчанию BFM прозрачно проксирует трафик всех процессов.
- Чтобы проксировать все процессы, кроме выбранных, откройте `/data/adb/box/settings.ini`, установите `proxy_mode` в `blacklist` (значение по умолчанию) и добавьте соответствующие GID в массив `gid_list`, разделяя их пробелами. Процессы с этими GID **не будут проксироваться**.
- Чтобы проксировать только выбранные процессы, установите `proxy_mode` в `whitelist` и добавьте нужные GID в `gid_list` через пробел. В этом случае проксироваться будут **только процессы с указанными GID**.
> **Совет:** iptables в Android не поддерживает сопоставление по PID, поэтому Box определяет процессы косвенно, по GID. В Android можно использовать команду `busybox setuidgid`, чтобы запускать процесс с заданным UID и любым GID.

### Изменение режима сети BFM
- По умолчанию BFM использует TPROXY для прозрачного проксирования TCP- и UDP-трафика. Если устройство не поддерживает TPROXY, откройте `/data/adb/box/settings.ini` и установите `network_mode` в `redirect`; в этом режиме проксируется только TCP.
- Параметру `network_mode` можно присвоить значение `redirect`, `tproxy` или `mixed`:
- `redirect`: проксирование TCP в режиме redirect.
- `tproxy`: проксирование TCP и UDP с помощью TPROXY.
- `mixed`: проксирование TCP в режиме redirect и UDP через TUN.
- Сохраните файл конфигурации, затем перезапустите службу BFM или устройство, чтобы изменения вступили в силу.

### Обход прозрачного прокси при подключении к Wi-Fi или точке доступа в BFM
- По умолчанию BFM прозрачно проксирует трафик localhost и точки доступа, включая USB-модем.
- Чтобы обходить прокси при подключении через Wi-Fi, откройте `/data/adb/box/settings.ini`, найдите параметр `ignore_out_list` и добавьте к нему `wlan+`.
- Чтобы проксировать трафик точки доступа, найдите параметр `ap_list` в `settings.ini` и добавьте к нему `wlan+`. На устройствах **MediaTek** может использоваться интерфейс **ap+** или **wlan+**.
- Если вы не знаете имя интерфейса точки доступа (AP), определите его с помощью команды `ifconfig` в терминале.

### Автоматическое обновление Geo и подписок по расписанию
- Откройте файл **/data/adb/box/settings.ini** с помощью текстового редактора.
- Найдите в файле параметр `run_crontab`.
- Измените значение `run_crontab` на `true`.
- Настройте параметр `interval_update` в соответствии с желаемым расписанием. Значение по умолчанию — **@daily**, что означает обновление один раз в день. Вы можете установить свой интервал, используя синтаксис cron.
- Сохраните изменения в файле конфигурации.
- Чтобы запустить задание Cron и обновления, выполните команду:

```shell
  # Запустить задание по расписанию
  su -c /data/adb/box/scripts/box.service cron
```

- Эта команда запустит задание Cron и обновление баз Geo и подписок по заданному расписанию.
- Убедитесь, что у вас есть необходимые права для выполнения команды. После включения и запуска задания обновления будут выполняться автоматически по расписанию.

## Запуск и остановка
### Ручной режим
- Чтобы управлять BFM вручную с помощью команд, создайте файл `/data/adb/box/manual`. В этом режиме служба BFM не запускается автоматически при включении устройства, а управлять ею через приложение Magisk/KernelSU Manager нельзя.
- Для изменения системных файлов необходимы соответствующие разрешения. Вносите изменения осторожно.

### Запуск и остановка службы управления
- Скрипт службы BFM находится по пути `/data/adb/box/scripts/box.service`

```shell
# Старт BFM
  su -c /data/adb/box/scripts/box.service start &&  su -c /data/adb/box/scripts/box.iptables enable

# Стоп BFM
  su -c /data/adb/box/scripts/box.iptables disable && su -c /data/adb/box/scripts/box.service stop
```

- При выполнении этих команд терминал будет одновременно выводить логи на экран и записывать их в лог-файл.

## Подписки и обновление баз данных Geo
Чтобы одновременно обновить подписку и базу данных Geo, выполните команду:

```shell
  # Обновить подписку и базу данных Geo
  su -c /data/adb/box/scripts/box.tool geosub
```

Их также можно обновить по отдельности:

### Обновление подписки:

```shell
  # Эта команда обновит данные подписки.
  su -c /data/adb/box/scripts/box.tool subs
```

Выполняйте эти команды, когда потребуется обновить подписку или базу данных Geo.

### Обновление базы данных Geo:

```shell
  # Эта команда обновит базу данных Geo.
  su -c /data/adb/box/scripts/box.tool geox
```

## Дополнительные инструкции
- При изменении конфигурационного файла ядра убедитесь, что параметры TPROXY соответствуют настройкам в `/data/adb/box/settings.ini`.
- Если у устройства есть публичный IP-адрес, его можно добавить во внутреннюю сеть в файле `/data/adb/box/scripts/box.iptables`, чтобы избежать циклов трафика.
- Логи BFM хранятся в каталоге `/data/adb/box/run`.
- Для редактирования этих файлов нужны соответствующие разрешения. Точно следуйте инструкциям и проверяйте все изменения конфигурации.

Выполните следующие команды, чтобы посмотреть другие инструкции по использованию:

```shell
  su -c /data/adb/box/scripts/box.tool
  # использование: {check|bond0|bond1|memcg|cpuset|blkio|geosub|geox|subs|upkernel|upyacd|upyq|upcurl|port|reload|all}
  su -c /data/adb/box/scripts/box.service
  # использование: $0 {start|stop|restart|status|cron|kcron}
  su -c /data/adb/box/scripts/box.iptables
  # использование: $0 {enable|disable|renew}
```

## Удаление
- При удалении модуля через Magisk/KernelSU Manager также удаляются файл `/data/adb/service.d/box_service.sh` и каталог данных BFM `/data/adb/box`.
- Чтобы удалить данные BFM вручную, выполните команду:

```shell
  # Удалить каталог данных BFM
  su -c rm -rf /data/adb/box
  su -c rm -rf /data/adb/service.d/box_service.sh
  su -c rm -rf /data/adb/modules/box_for_root
```
